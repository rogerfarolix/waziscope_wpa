# WaziScope : application Laravel

Passerelle API et front Vue 3 de WaziScope. La documentation complète (installation, déploiement, limites par plateforme) se trouve dans le [README principal](../README.md).

- Contrôleur : `app/Http/Controllers/VideoController.php`
- En-têtes de sécurité (CSP, HSTS) : `app/Http/Middleware/SecurityHeaders.php`
- Routes : `routes/api.php`
- Front : `resources/js/` (vue d'accueil : `views/HomeView.vue`)
- Tests : `php artisan test`
